未達ペアの反復と、新しいペア

数日ぶりに、3-style（エッジ）の反復練習を行いました。前回未達だった UF → BD → BR、UF → BD → DF、UF → BD → DL を中心に42セット回して、新しいペア UF → BD → DR にも入りました。

一番の変化は UF → BD → BR です。前回は ao5 が DNF でしたが、今回は最後まで回せるようになって、ao5 8.08 と一次合格（sub8）まであと0.08秒のところまで来ました。UF → BD → DF は ao5 10.32、UF → BD → DL は 10.00 で、どちらも前回から縮んでいます。一次合格済みの UF → BD → BL は 7.15、UF → BD → BU は 6.46 でした。

3×3×3 は22本回して、ベストは 15.95、最後の ao5 は 18.87 でした。
