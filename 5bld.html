5BLD 手順別練習表

5BLD（5×5×5の目隠し）の手順を、パートごとにまとめた練習表です。方式はcubevoyageの「5BLD入門」「4BLD入門」に沿っていて、手順はすべてシミュレータで検証済みです。計測は、どのパートも手順を2回通してピースが元に戻るまでの「往復」を1回として、往復ベストと往復ao5を記録します。

進み具合

  • 全体: クリア 0 / 116
  • コーナーOP: 0 / 21
  • ミドルエッジM2: 0 / 22
  • ウィングエッジr2: 0 / 23
  • XセンターU2: 0 / 23
  • +センターU2: 0 / 23
  • パリティ: 0 / 4

解く順番は、Xセンター → +センター → ウィングエッジ → ミドルエッジ → コーナーの順が推奨されています。この順なら、センターへの影響を考慮しなくてよいそうです。

計測は往復が単位です。ただし「ペア型」の手順（単体を2回回しても元に戻らないもの）は、対になる手順を続けて回すことで往復になります。対象は、M2の UF⇔DB と か⇔つ、r2の FU⇔BD、Xセンターの Ufl⇔Ubr、+センターの Ul⇔Ur です。実ソルブでも、これらは偶数番目の実行では対の手順を使うルールがあります。

レター配置図

各パーツのレター（かな）を、キューブの展開図に書き入れたものです。見やすいように、ピースの種類ごとに展開図を分けました。各図では、そのピース種のマスだけに色とレターを入れ、ほかのマスは薄いグレーにしています。色の濃いマスは、そのピース種のバッファのステッカーです。面の色は、自分のキューブの配色（U面=白、F面=赤、B面=オレンジ、R面=青、L面=緑、D面=黄）に合わせています。ウィングのレターは、対応するミドルエッジのレターを流用した暫定の割り当て（※）です。ウィングは、レターを割り当てた向きのステッカーにだけレターを付け、もう一方のステッカーは読まないため黒塗りにしています。

コードとレターについて

  • コードは、ピースの種類を表すプレフィックスと、その対象のレター（ローマ字）を組み合わせたものです。コーナーは C（例: Ci、Cku）、ミドルエッジは m（例: mk）、ウィングは w（例: wa）、Xセンターは x（例: xa）、+センターは p（例: pka）です。パリティは専用コードで、センターが pc、ウィングが pw、ミドルエッジ×コーナーが pm1（前処理）と pm2（本手順）です。csTimerの備考欄にこのコードを書いて記録します。
  • コーナーのレターは、自分の体系（各面を正面から見て左上から時計回り。U面=あいうえ、F面=かきくけ、R面=さしすせ、B面=たちつて、L面=まみむめ、D面=らりるれ）です。バッファUBLのU面ステッカー「あ」は対象外です。
  • ミドルエッジのレターは、3BLDで使っている既存の体系です。ただしUFエッジの2ステッカー（う・か）はその体系に無いため、cubevoyageのナンバリングから補いました（表で ※ を付けたもの）。D面は自分の体系とcubevoyageで「り」「れ」が逆ですが、この表は自分の体系に合わせています。
  • Xセンターのレターは、cubevoyageの原則「センターにはコーナーのナンバリングを流用」に沿って、コーナーのレターで割り当てました。+センターのレターは「+センターにはエッジのナンバリングを流用」に沿って、エッジのレターで割り当てています（Uf・Fuの2件は ※ で、cubevoyageから補いました）。ただしD面の4件だけは専用ナンバリングで、Dl寄り=ら、Df寄り=り、Dr寄り=る、Db寄り=れ です。

パリティの扱い

  • センター（X・+共通）: パリティは、センター実行の最後にU2を1回追加するだけです。
  • ウィング: パリティ手順（DFr⇔UFr）は、センターを揃えてから実行します。最後の1文字をFUにセットアップしてこの手順を回し、逆セットアップするのが基本です。
  • ミドルエッジ×コーナー: 同時に発生し、同時に処理します。ミドルエッジ（M2）を実行し終わった直後に前処理を回し、コーナー（OP）の最後の一文字の手順を回した直後に本手順を回します。本手順はセンターを崩すので、センターを揃えてから実行します。なお、4BLDのコーナーパリティ手順は+センターが崩れるため、5BLDでは使いません。
  • EO（エッジ反転）: 有名なEO処理手順はどちらもセンターの配置が崩れるため使わず、EOの2文字をM2法で処理するのが楽だそうです。
  • ミドルエッジの旧手順の使用禁止: 3BLDのUF手順（U2 M' U2 M'）・DB手順（M U2 M U2）・BU手順（F2で挟むEO系など）は、センターの配置が崩れるため5BLDでは使いません。代わりに、表の差し替え手順を使います。

コーナーOP（21対象）

バッファはUBL（あ）です。Yパーム (Y) = R U' R' U' R U R' F' R U R' U' R' F R で、表の手順は「セットアップ (Y) 逆セットアップ」の形です。Yパームはバッファステッカー（あ）とDFRのR面ステッカー（せ）を直接交換します。副次効果として毎回 UL⇔UB のミドルエッジとそのウィングが入れ替わります（偶数回で相殺し、奇数回分はパリティ処理で戻します）。出典ページにOPのセットアップ一覧が無いため、セットアップはシミュレータで生成し、すべて検証済みです。3BLDで使っているセットアップと異なるものは、差し替えても構いません。バッファピース自身のステッカー（ち・ま）は対象に含めません。

ウィングエッジr2（23対象）
